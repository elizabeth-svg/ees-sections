# Motion DOM contract — ees-sections/assets/motion.js

**Durable reference.** This documents the hooks the SHARED motion engine
(`assets/motion.js`) queries. Any page rebuilt with dc-page-rebuild must emit these
`data-*` hooks for the corresponding effect to run. If you port NEW motion for a page
(dc-motion-port), update this file in the same commit. The Home page is the worked
example below; treat each effect as "present only if the page uses it".

---

# 03 — Motion DOM Contract (`motion.js`)

`motion.js` is a framework-free port of the Claude-Design "DCLogic" `Component`
from `Home.dc.html`. It self-boots on `DOMContentLoaded`, waits for
`document.fonts.ready` (falling back if the API is absent), does one
`requestAnimationFrame`, then runs `boot()`. `boot()` polls for
`window.gsap` + `window.ScrollTrigger` for up to ~20 seconds before giving up,
so the CDN scripts may still be arriving when it first runs.

Every selector below is queried against `document`. Nothing is created for you —
the page markup must already carry these `data-*` hooks and structure or the
corresponding effect silently no-ops. All hooks are **attribute selectors**
(`[data-x]`), never classes, except the split-word class `.w` (generated by the
script) and the `<footer>` / `> div` / `h1` structural selectors noted below.

---

## 1. Required CDN scripts (exact versions, in load order)

These must all load **before** `motion.js`. Versions are taken from the design
`<head>`. Lenis is optional to the *effects* but the smooth-scroll and the
navigator's `scrollTo` depend on it; gsap + ScrollTrigger are mandatory (boot
aborts without them); SplitText is optional (a manual word-splitter is the
fallback).

```html
<script src="https://cdn.jsdelivr.net/npm/lenis@1.1.20/dist/lenis.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrollTrigger.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/SplitText.min.js"></script>
<!-- then, after these: -->
<script src="motion.js"></script>
```

Load order matters: `gsap` before its plugins; all four before `motion.js`.
The script registers `ScrollTrigger` always, and `SplitText` only if present.

Globals it reads/writes: `window.Lenis`, `window.gsap`, `window.ScrollTrigger`,
`window.SplitText`, and its own `window.__eesLenis` (the live Lenis instance,
used by the navigator to `scrollTo`) and `window.__eesEngine` (the velocity
ticker callback, removed on hot-reload).

## 2. Props (baked in, no editor)

DCLogic's injected `this.props` is now a fixed object at the top of the IIFE:

```js
var props = { wordmarkFont: "Rockybilly", accentColor: "#f2ea36", motionIntensity: 1 };
```

- `wordmarkFont` — selects a face from the `faces` map and, if set, writes
  `font-family/size/letter-spacing/line-height/text-transform` onto `[data-mark]`
  (hero size) and `[data-nav-mark]` (nav size). Valid keys: `Rockybilly`,
  `Sedgwick Ave Display`, `Permanent Marker`, `Caveat Brush`, `Rubik Spray Paint`
  (unknown → `Rockybilly`). The matching `@font-face`/Google Fonts must be loaded.
- `accentColor` — hover title colour, active navigator colour (`#f2ea36`).
- `motionIntensity` — multiplies the generic-fade rise distance (`y: 22 * intensity`).

## 3. Effects → DOM hooks (grouped)

### 3.1 Hero: scatter → system, wordmark flight, showreel
The whole hero is one pinned ScrollTrigger on `[data-hero]`
(`start:'top top'`, `end:'+=280%'`, `scrub:1.2`, `pin:true`).

Required for the flight to run (`if (hero && mark …)`):
- `section[data-hero]` — the pinned hero section (also carries `data-screen-label`; see §3.5).
- `[data-mark]` — the big hero wordmark/monogram that flies. **Also the font target.**
- `[data-nav-mark]` — the fixed nav-slot wordmark the flight lands on. **Also a font target.**
  Kept `autoAlpha:0` until the flight completes (`onLeave`), restored on `onEnterBack`.

Animated within the hero timeline (each optional, no-op if absent):
- `[data-hero-stage2]` — secondary hero block that blurs/rises in at 0.58. If the
  flight branch does *not* run (no hero/mark, or reduced motion) it is set
  `display:none`.
- `[data-hero-scrim]` — darkening scrim, fades to `opacity:1`.
- `[data-hero-text]` — hero text group, fades/blurs out as you scroll (queried via `q`).
- `[data-reel-video]` — the showreel `<video>`; scales to 1.16 across the pin.

Mosaic tiles (the scatter→grid):
- `[data-tile]` — **every mosaic frame.** Each **must** carry
  `data-from="up|down|left|right|fade"` — this drives which side it gathers from.
  `data-from="fade"` marks the centre "aperture" panel (opens via `scaleY`).
  Contract: `[data-tile][data-from]`. Without `data-from` a tile defaults to `up`.

Showreel controls (all optional; wired only if `[data-reel-video]` exists):
- `[data-reel-toggle]` — play/pause button (gets `aria-label`, click handler).
- `[data-reel-label]` — text node set to "Play reel" / "Pause reel".
- `[data-reel-glyph]` — the play/pause glyph (width/border set to draw ▶ or ❚❚).

Hero intro copy (independent of the pin, plays on load):
- `[data-hero-copy] h1[data-split]` — the hero H1. **Must be an `<h1>` with
  `data-split` inside `[data-hero-copy]`.** Words are split and rise in.
- `[data-hero-copy] [data-fade]` — sub-copy bits that fade up (staggered). Note the
  generic-fade pass explicitly skips anything inside `[data-hero-copy]`.

### 3.2 Two-tone scrubbed statements
- `[data-scrub]` — any block whose words light from 28% → 100% opacity as it
  scrolls (`start:'top 84%'`, `end:'bottom 48%'`, `scrub:0.96`). Words are wrapped
  in `.w` spans by the splitter. Under reduced motion they are set solid.

### 3.3 Approach spotlight sentence
- `section[data-approach]` (also carries `data-screen-label`) — pinned
  (`end:'+=180%'`, `scrub:1.2`).
  - `[data-approach] [data-spotlight]` — the single over-wide sentence that
    travels horizontally while each word lights by proximity to centre. Words are
    wrapped `.w`. Reduced motion: wraps normally, all words solid, no pin.

### 3.4 Section handoff (float + reveal + exit dim)
Structural selector — **no dedicated attribute**:
```
section[data-screen-label]:not([data-hero]):not([data-approach]) > div
```
So every non-hero, non-approach section that participates **must**:
- be a `<section data-screen-label="…">`, and
- wrap its content in exactly **one direct child `<div>`** (the `> div`).
That inner `<div>` gets three tweens: a parallax float (scrubbed over the parent
section), an entrance rise/fade (per-section stepped rise 46/72/0, dur, ease), and
a scrubbed exit dim. Reduced motion: inner div set `autoAlpha:1`.

### 3.5 Section labels / page navigator
- `section[data-screen-label="NAME"]` — **every screen section carries a unique
  label.** These are the scroll-spy targets and the jump targets.
- `[data-navigator]` — the navigator container. Hidden (`autoAlpha:0`) until the
  hero hands over (`ScrollTrigger` on `[data-hero]` `start:'bottom 80%'`).
  - `[data-goto="NAME"]` — one button per destination; its `data-goto` value **must
    match** a `section[data-screen-label="NAME"]`. Contract:
    `[data-navigator] [data-goto]` ↔ `section[data-screen-label]`.
    - `[data-goto-idx]` (inside each button) — index glyph, recoloured on active.
    - `[data-goto-name]` (inside each button) — label, recoloured on active.
  - `[data-nav-progress]` — text node set to the active section's zero-padded number.
  Clicking a button scrolls via `window.__eesLenis.scrollTo` (Lenis) or native
  smooth scroll. A ScrollTrigger per matched section (`top 55%`→`bottom 45%`)
  drives the active paint.
- `[data-corner]` — navigator corner wrapper; toggled `flex`/`none` at ≥760px width.
- `[data-nav-pill]` — queried (`pill`) but currently unused; harmless if absent.

### 3.6 Generic fades
- `[data-fade]` — anything fades/blurs up on entry (`start:'top 90%'`), **except**
  elements inside `[data-hero-copy]` (handled by the hero intro). Skipped entirely
  under reduced motion.

### 3.7 Crosshair cursor (pointer:fine, hover only, non-reduced)
- `[data-cross]` — the crosshair container, revealed on first `mousemove`.
  - `[data-cross-v]` — vertical hairline (x-tracks pointer, snaps to frame lines).
  - `[data-cross-h]` — horizontal hairline (y-tracks pointer).
  - `[data-disc]` — the pointer disc; scales up over any `a[href]` / `button`.

### 3.8 Row / case hover
- `[data-row]` and `[data-case]` — hover targets.
  - title: `[data-row-title]` or `[data-case-title]` — shifts to accent (rows also
    translate x:10).
  - `[data-row-meta]` — meta text, recoloured on hover.
  - `[data-case-inner]` — inner media, scales to 1.04 on hover.

### 3.9 Scroll engine (single smoothed velocity)
Runs unless reduced motion. Reads velocity from a document-spanning ScrollTrigger
and drives:
- `[data-scrub], [data-spotlight]` — skewY (≤ 2.6°).
- `[data-rule]` — opacity lift.
- `[data-rails]` (single element) — opacity lift. Optional.

### 3.10 Self-drawing hairline rules
- `[data-rule]` — each rule draws L→R via `scaleX 0→1` (`start:'top 94%'`).
  Reduced motion: set `scaleX:1` (drawn, static). (Also used by the scroll engine.)
  These elements should have `transform-origin` at the left edge in CSS.

### 3.11 Client-mark parallax
- `[data-mark-cell]` — client logo cells. The row is `cells[0].parentNode`
  (**all cells must share one parent**). Each cell parallax-travels vertically at
  its own rate over the row's scroll. Non-reduced only.

### 3.12 Footer glow
- `[data-footer-glow]` — gradient blob; slow yoyo drift + parallax over its
  enclosing `<footer>` (`glow.closest('footer')` **must exist**). Non-reduced only.

### 3.13 Scroll cue
- `[data-cue]` — the cue container; retires (fades out) on first scroll.
  - `[data-cue-dot]` — the travelling dot (looping tween). Non-reduced only.

### 3.14 Refresh triggers (layout re-measure)
- `[data-mosaic] img` — mosaic images; a `load` listener re-runs
  `ScrollTrigger.refresh()` so pin geometry is correct once art arrives. (`[data-mosaic]`
  is the wrapper element around the mosaic imagery.)
- `[data-reel-video]` also refreshes on `loadedmetadata`.
- Plus `window 'load'` and `document.fonts.ready`.

## 4. Strict structural requirements (beyond a lone attribute)

These are the ones page markup **must** get exactly right — an attribute in the
wrong shape breaks the effect silently:

1. **Mosaic tiles:** `[data-tile][data-from]` — every tile needs a `data-from`
   of `up|down|left|right|fade`; one `fade` tile = the centre aperture.
2. **Hero landmarks:** `[data-mark]` (flies) and `[data-nav-mark]` (lands) must
   both exist for the flight, plus `section[data-hero]` and (optionally)
   `[data-hero-stage2]`, `[data-hero-scrim]`, `[data-hero-text]`.
3. **Hero H1:** must be `[data-hero-copy] h1[data-split]` — an actual `<h1>` with
   `data-split`, nested in `[data-hero-copy]`.
4. **Section handoff:** each participating section is
   `section[data-screen-label]` (not hero/approach) with **exactly one direct
   child `<div>`** wrapping its content.
5. **Navigator wiring:** each `[data-navigator] [data-goto="NAME"]` must match a
   `section[data-screen-label="NAME"]`; buttons contain `[data-goto-idx]` and
   `[data-goto-name]`; `[data-nav-progress]` present for the counter.
6. **Approach:** `section[data-approach]` containing a `[data-spotlight]` child.
7. **Client marks:** all `[data-mark-cell]` share a single parent row.
8. **Footer glow:** `[data-footer-glow]` must be inside a `<footer>`.

## 5. Reduced-motion behaviour (`prefers-reduced-motion: reduce`)

Checked twice: `reduceEarly()` (before Lenis) and `reduce` (inside boot). When
reduced motion is on:

- **Lenis is not started** — native scrolling only; the navigator falls back to
  native `window.scrollTo({behavior:'smooth'})`.
- **Hero flight/scatter does not run.** Instead: `[data-nav-mark]` set
  `autoAlpha:1`, all `[data-tile]` set `autoAlpha:0` (mosaic hidden),
  `[data-hero-stage2]` set `display:none`. Hero H1 word-rise and hero sub-fades
  are skipped.
- **Two-tone `[data-scrub]`** words set to solid `opacity:1` (no scrub).
- **Approach `[data-spotlight]`** wraps to normal flow with a fluid font size and
  padding, all words solid — no pin, no travel.
- **Section handoff** inner `<div>`s set `autoAlpha:1` (visible, no float/rise/dim).
- **Generic `[data-fade]`** skipped (elements remain in their natural state).
- **`[data-rule]`** set `scaleX:1` (drawn, no self-draw animation).
- **Crosshair cursor, scroll engine (skew/rule/rail), client-mark parallax,
  footer glow, and scroll cue** are all skipped.
- **Showreel video** is paused by default (not autoplayed); the toggle still works.
- Static reveals therefore guarantee the page is fully legible with no scroll-tied
  motion. Hover effects on rows/cases and the navigator scroll-spy still function
  (they are not motion-gated), and `ScrollTrigger.refresh()`/`sort()` still run.
