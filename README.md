# EES Sections

Editable design-system section blocks for **eaglesimbeye.com**.

Each section of the site's design is a native, editable WordPress block with the
design baked into the plugin's CSS — so the page looks right *and* every section
stays editable in the standard block editor. No page-builder lock-in, no build step.

## Blocks

- **EES Statement** — eyebrow, statement headline, paragraph, and a call-to-action.

_(More section blocks — Hero, Spotlight, Numbered rows, Featured case, Client
logos, Article rows, Footer CTA — added as the build progresses.)_

## Install

Installed and updated via the Respira ZIP-URL flow. No build toolchain required.
